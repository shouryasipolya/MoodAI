# 🎵 MoodAI – Music Recommendation System

MoodAI is an AI-based music recommendation system that analyzes a user's facial expression and recommends music according to the detected mood.

## ✨ Features

- User registration and login
- Webcam-based facial expression detection
- Mood classification
- Personalized music recommendations
- Mood analytics
- Database integration
- Interactive web interface

## 🛠️ Technologies Used

- Python
- Flask
- TensorFlow
- OpenCV
- MySQL
- HTML
- CSS
- JavaScript
- Spotify API

## 🧠 How It Works

1. User opens the application.
2. The webcam captures the user's facial expression.
3. The system processes the image using computer vision.
4. A machine-learning model detects the user's mood.
5. The detected mood is used to generate suitable music recommendations.

## 🎯 Objective

The goal of MoodAI is to combine computer vision, machine learning, and web development to create a mood-based music recommendation experience.
